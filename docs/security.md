# Защита данных и границы действий консультанта

API ограничивает тело запроса 16 КиБ, длину текста и набор параметров. Очевидные инструкции о смене роли, раскрытии секретов и внешних действиях блокируются до запроса к модели. Текстовые фрагменты документов с такими инструкциями исключаются из контекста.

Аргументы инструментов проверяются по схемам и разрешённому списку. Код инструментов содержит только чтение каталога с подготовленными параметрами, без доступа к оболочке, произвольному SQL или операциям магазина. Факты о товарах и ссылки перепроверяются на сервере. Ошибка модели сохраняет режим каталога.

UUID сессии используется вместе со случайным секретом владельца. Все операции с историей, потоком и оценкой проверяют принадлежность сессии. Ответы Chat API содержат `Cache-Control: no-store`. Ошибки валидации возвращают тип, место и описание. Параметры SQL скрываются, трассировка LangSmith отключена для входных сообщений.

Распознавание очевидных инструкций зависит от формулировки. Незнакомая формулировка может попасть в контекст и повлиять на выбор из разрешённых товаров. Поэтому операции, доступ и вывод фактов ограничены типизированными серверными правилами. При публичном развёртывании терминируйте TLS на доверенном прокси и ограничьте доступ к Ollama, PostgreSQL и Redis сетью сервисов.
