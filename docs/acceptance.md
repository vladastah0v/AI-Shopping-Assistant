# Приёмка AI Shopping Assistant

## Объём

Приложение публикует 22 операции OpenAPI. В каталоге `app` 63 файла Python, включая точки входа пакетов. Каталог использует PostgreSQL 16 с pgvector, а временное состояние, кэш и лимиты работают через Redis. Языковая модель подключается локально через Ollama. Модели, ресурсы и команды приведены в инструкциях. [Архитектура](architecture.md) · [Эксплуатация](operations.md) · [Embeddings](embeddings.md) · [Ollama](ollama.md).

| Раздел | Операции |
|---|---|
| Каталог | Категории, бренды, список и карточка товара, характеристики, сравнение |
| Поиск | Полнотекстовая, семантическая и гибридная стратегии |
| Диалоги | Создание, список, чтение и удаление сессий, отправка, чтение и очистка сообщений, SSE и оценка ответа |
| Состояние | `/health/live`, `/health/ready`, `/health/ai` и `/metrics` |

Приёмка использует синтетический каталог `small` с seed 42. В наборе 100 товаров и 400 документов. Факты для ответа берутся из карточек. Обязательные ограничения проверяются в поисковых запросах, а ссылки модели сопоставляются с разрешёнными товарами и документами.

## Как воспроизвести

```bash
./scripts/ci_checks.sh
```

Скрипт собирает API, применяет миграции до `0008`, проверяет расхождения схемы Alembic и запускает тесты с реальными PostgreSQL и Redis. Контейнерный сценарий проверяет каталог, изоляцию сессии, чат, SSE, оценку и сбор метрик. [Сценарий диалога](operations.md#проверяемый-диалог) · [Мониторинг](observability.md) · [CI](ci.md).

## Результаты 28 ноября 2026 года

- Полный локальный прогон `./scripts/ci_checks.sh` дал 113 успешных тестов без падений и пропусков. Покрытие строк приложения — 91%. Обе проверки Ruff, lock-файл, варианты Compose и `alembic check` прошли.
- На запущенном контейнерном стеке подтверждены контракт OpenAPI, поиск по артикулу, резервная выдача, сохранение бюджета при уточнении, ответ о нулевом остатке, SSE и запись оценки. Prometheus собрал метрики, Grafana загрузила восемь панелей.
- Gitleaks проверил историю репозитория без находок. GitHub Actions для коммита `773bfa8` завершился успешно. Изменения приёмки проверены локально. [Запуск GitHub Actions](https://github.com/vladastah0v/AI-Shopping-Assistant/actions/runs/46011532546).

## Качество и производительность

Набор `small-42-v2` проверяет 144 сценария поиска и диалога. Протокол содержит метрики по намерениям, соблюдению бюджета и характеристик, подтверждённости карточек и источников. В режиме каталога все 144 сценария дали ожидаемое поведение. Бюджет и характеристики соблюдены во всех измеренных случаях. Обработчик отклонил 24 из 24 ненадлежащих команд из набора. [Методика](evaluation.md) · [Результаты](evaluation-results.json).

Проверки производительности используют 100 синтетических векторов размерности 384 для сравнения exact, HNSW и IVFFlat. Измерение поиска с Redis и без него и дымовой прогон Locust сохранены с исходными данными. [Отчёты и график](benchmarks.md).

## Ограничения приёмки

- Запуск с оригинальными весами multilingual E5 и реальной Ollama — `NOT_RUN`. Хранилище и поиск по векторам проверены на тестовых векторах, HTTP-протокол Ollama — с тестовым транспортом, а проверка ответов RAG — с тестовым провайдером.
- Качество реальных моделей, семантической и гибридной выдачи с весами E5, задержки генерации и время до первого токена — `NOT_MEASURED`.
- Нагрузочный прогон профиля `large` — `NOT_RUN`. Метрики малого набора описывают эксперимент на данном оборудовании.
- Покрытие относится к процессу pytest. Покрытие отдельных контейнеров — `NOT_MEASURED`.
