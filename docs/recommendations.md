# Рекомендации, альтернативы и сравнение

Рекомендации выбираются из выдачи после обязательных ограничений. Для каждого выбранного товара приложение возвращает причину выбора.

- Оптимальный вариант — первый в релевантной выдаче с приоритетом доступных товаров.
- Бюджетный вариант — минимальная цена среди оставшихся кандидатов в той же валюте, если она не выше цены оптимального варианта.
- Вариант по характеристикам — оценка сравнимых числовых показателей внутри одной категории. Каждый известный показатель нормируется по максимуму среди кандидатов. Вариант показывается, если его оценка выше оценок уже выбранных товаров.
- Альтернатива — другой товар с сохранением ограничений. Для запроса дешевле одновременно действуют прежний бюджет и требование цены строго ниже цены исходного товара.

Сравнение принимает от двух до пяти явных товарных ссылок, сохраняет их порядок и читает характеристики с карточек. Пропущенные значения отображаются как `null`. Если исходный товар неизвестен или часть сравниваемых товаров недоступна, консультант запрашивает уточнение.
