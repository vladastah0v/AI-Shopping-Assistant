## Текущее состояние

Точный поиск и HNSW находят товары и фрагменты документов в заданной версии embeddings с учётом фильтров каталога. Команда переиндексации переключает оба индекса в одной транзакции. Пройдено 67 тестов, покрытие строк `app` в процессе pytest — 94%. [Векторный поиск и переиндексация](vector-search.md).

Следующий этап — полнотекстовый поиск PostgreSQL по русскоязычным запросам, артикулам, моделям и техническим терминам.
