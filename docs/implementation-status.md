## Текущее состояние

Публичный API каталога предоставляет категории, бренды, фильтры товаров, карточки, характеристики и сравнение. Маршруты и обработка недоступности PostgreSQL проверены на наполненном каталоге в Docker Compose. Пройдено 49 тестов, проверки Ruff выполнены успешно. Покрытие строк `app` в процессе pytest на этапе 4 составило 96%. [Документация API](api.md).

Следующий этап — выбор мультиязычной модели и генерация embeddings для товаров и фрагментов документов.
