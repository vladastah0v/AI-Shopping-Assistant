## Текущее состояние

Поиск и векторы используют отдельные версионированные кэши с TTL и блокировкой вычисления. Миграция 0008 обновляет ревизию при изменении каталога. Redis атомарно ограничивает частоту запросов и число активных сообщений. [Кэширование и настройки](redis.md).
