## Текущее состояние

Реализован асинхронный Ollama-провайдер с таймаутами, повторами, ограничением генераций, JSON Schema и потоком NDJSON. Добавлены отдельная проверка готовности модели и профиль Compose для локальной генерации. [Запуск и параметры](ollama.md).

Следующий этап — LangChain, намерения и извлечение требований.
