# Оценка поиска и ответов

Контрольный набор `small-42-v1` содержит 144 русскоязычных сценария, по 12 на каждую группу. Проверяются поиск по артикулу и назначению, бюджет, характеристики, сравнение, наличие, цена, уточнения диалога, пустая выдача, неоднозначность, попытки изменить инструкции и запрещённые инструменты. Ожидания определяются версией [набора](../app/evaluation/scenarios.py) и генератором каталога с seed 42.

```bash
uv run --locked python -m scripts.seed_catalog --profile small --seed 42
uv run --locked python -m scripts.evaluate --output evaluation.json
```

Запускайте оценку с учётной записью, которая может создать тестовые сеансы. Каждый сценарий откатывает запись диалога. `--vectors` добавляет семантический и гибридный поиск и требует заранее подготовленных весов и векторов. `--ollama` проверяет настроенную локальную модель. [Подготовка embeddings](embeddings.md) · [Настройки Ollama](ollama.md).

| Метрика | Расчёт |
|---|---|
| Precision@K | Число релевантных позиций среди первых K, делённое на K |
| Recall@K | Доля эталонных товаров, найденных среди первых K |
| MRR | Среднее обратное место первого релевантного товара |
| nDCG@K | Дисконтированный бинарный gain относительно идеального порядка |
| Intent accuracy | Доля ожидаемых намерений |
| Groundedness | Доля карточек и ссылок, подтверждённых контрольным каталогом |
| Budget и specification compliance | Доля карточек и отдельных проверок, соответствующих условиям |
| Invalid product recommendations | Доля карточек, которые нельзя подтвердить эталонным каталогом |
| Tool execution success | Доля ожидаемо успешных операционных сценариев, вернувших товары |
| Prompt injection attack success | Доля сценариев нарушения, в которых обработчик не отказал |

Ранжирование оценивается только по сценариям с поисковой фразой и эталонными релевантными товарами. Используется K=5. Диалоги оцениваются отдельно по ожидаемому поведению. Отсутствующий знаменатель или пропущенная стратегия отмечаются `NOT_MEASURED`.

[Фактический протокол локального прогона](evaluation-results.json) относится к режиму каталога. Измерение реальных моделей и сравнение семантической и гибридной выдач зависят от доступных весов.
