# Сессии и память диалога

Сессия принадлежит владельцу секретного токена из 32 случайных байт. В PostgreSQL хранится SHA-256 токена. Чтение, изменение и удаление привязаны одновременно к UUID сессии, хешу и сроку её действия. Один владелец может создать и перечислить несколько своих сессий.

PostgreSQL хранит сообщения в последовательности ходов и отдельно хранит категорию, бюджет, характеристики, поисковую формулировку, предпочтения и показанные товары. Redis хранит временную копию структурированного состояния по версионированному ключу. Приложение сначала подтверждает владельца и ревизию в PostgreSQL. При промахе или ошибке Redis читается актуальное состояние базы.

Уточнение характеристики заменяет её ранее заданное условие. Остальные обязательные фильтры сохраняются. При переходе в другую категорию очищаются ограничения на характеристики прежней категории. Ссылки «первый» и «третий» разрешаются по последнему упорядоченному списку товаров. При отсутствии нужной позиции требуется уточнение.

Срок сессии по умолчанию — 24 часа с последнего изменения. История читается ограниченными страницами. Очистка удаляет сообщения и повышает ревизию состояния. Удаление сессии каскадно удаляет историю. Настройки доступны через `SHOPPING_CHAT_SESSION_TTL_SECONDS` и `SHOPPING_CHAT_HISTORY_LIMIT`.
