# Инструменты консультанта

Распознанное намерение и идентификаторы товаров преобразуются сервером в ограниченную команду. Такой режим позволяет работать с моделями, у которых нет надёжного нативного Tool Calling. Интерфейс Ollama поддерживает собственный формат вызовов, в этом сервисе маршрутизация выполняется на стороне приложения.

| Инструмент | Действие |
|---|---|
| `search_products` | Поиск по условиям каталога |
| `get_product_details` | Чтение карточек |
| `compare_products` | Сравнение характеристик в исходном порядке |
| `check_stock` | Проверка остатка |
| `get_product_price` | Проверка актуальной цены |
| `get_product_specifications` | Чтение характеристик |
| `find_alternatives` | Подбор по категории и обязательным условиям |
| `get_category_information` | Чтение категории по её коду |

Имя допускается только из списка, аргументы проверяются отдельными схемами Pydantic, вызовы ограничены тремя операциями и общим таймаутом. Для поиска и альтернатив установлен лимит не более 20 карточек. Все операции читают каталог. Технический журнал фиксирует имя инструмента и время выполнения без аргументов.
